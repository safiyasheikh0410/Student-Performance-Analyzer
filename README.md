Student Performance Analyzer

Project Overview

Student Performance Analyzer is a simple web-based application developed as a Web Technology mini project. It helps analyze a student's academic performance by taking marks for different subjects and automatically calculating the total marks, percentage, grade, and overall pass/fail status.

The project is designed using basic web technologies and provides a simple and user-friendly interface.

Technologies Used

- HTML – Used to create the structure of the webpage.
- CSS – Used to design and style the webpage.
- JavaScript – Used to perform calculations, validation, and display the results.

Subjects

The analyzer includes the following subjects:

1. Data Structures
2. Digital Economy and Management
3. Probability Theory and Statistics
4. Open Elective
5. Computer Architecture
6. Professional Communication

Features

- Student name and roll number input
- Marks input for six subjects
- Marks validation between 0 and 100
- Automatic calculation of total marks
- Automatic calculation of percentage
- Automatic grade calculation
- Subject-wise Pass/Fail status
- Overall Pass/Fail result
- Performance analysis message
- Reset option to clear the entered data
- Responsive design for different screen sizes

Grading System

Percentage| Grade
90–100| A+
80–89| A
70–79| B
60–69| C
40–59| D
Below 40| F

A student must score at least 40 marks in every subject to be considered as passed.

How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Enter the student's name, roll number, and marks.
5. Click Analyze Performance.
6. The performance report will be displayed on the webpage.

Project Objective

The main objective of this project is to develop a simple web application that can analyze student academic performance using HTML, CSS, and JavaScript while demonstrating basic concepts of Web Technology.
